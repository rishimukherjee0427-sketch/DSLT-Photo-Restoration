# Citation check (refs.bib), 2026-11-25

Method: Crossref API records (api.crossref.org/works/<doi>), CVF open-access BibTeX (openaccess.thecvf.com), NeurIPS proceedings/virtual site, arXiv, PubMed (IEEE-supplied metadata for TPAMI), ORCID, and web search for Springer/JSTOR/OpenReview pages that blocked automated fetching (Springer, OpenReview, AAAI OJS, DBLP, IEEE Xplore returned bot walls). DOIs were added only where Crossref resolved them to the same title. The `verify` field was deleted from every entry.

Page-number policy for CVPR: where an IEEE DOI exists, the IEEE Xplore/Crossref page range is used so DOI and pages agree. For Restormer and AirNet the CVF BibTeX gives different page numbers (see notes); both are primary-source values.
